# Handoff: MUZE — 헤어/네일 모델 매칭 앱 (모바일 웹)

## Overview
헤어샵·네일샵 디자이너가 개인 포트폴리오 작업용 **모델을 구인**하고, 헤어/네일 모델을 하고 싶은 일반인이 **사진 3장 + 본인 조건**으로 지원하는 모바일 서비스. 지원자와 디자이너는 인스타그램·카카오톡 오픈채팅 링크로 연결된다.

핵심 규칙:
- 지원 시 사진 3장 필수
  - 메인 1장: 헤어 모집 = 정면 얼굴 사진 / 네일 모집 = 손톱이 보이는 손등 사진
  - 추가 1장: 현재 상태 사진
  - 추가 1장: 최종 희망 결과물 스타일 사진
- 지원서와 지원자 상세 양쪽에 인스타그램 계정 임베드 + 카카오톡 오픈채팅 링크 임베드

## About the Design Files
이 번들의 HTML 파일은 **디자인 레퍼런스**다. 의도한 화면과 동작을 보여주는 프로토타입이며 그대로 프로덕션에 붙여 쓰는 코드가 아니다. 목표는 이 디자인을 **대상 코드베이스의 기존 환경(React/Next.js, Vue, SwiftUI 등)과 기존 패턴·라이브러리로 재구현**하는 것이다. 아직 코드베이스가 없다면 적합한 프레임워크를 직접 고르고(권장: Next.js + TypeScript + Tailwind CSS, 이미지 업로드가 핵심이므로 Supabase Storage 또는 S3) 그 위에 구현한다.

`Model Matching App.dc.html`은 커스텀 스트리밍 런타임(`support.js`) 위에서 도는 파일이라 그대로 열면 동작하지 않을 수 있다. 마크업과 인라인 스타일, 로직 클래스(`class Component extends DCLogic`)의 데이터·상태·핸들러를 **읽기용 스펙**으로 사용할 것.

## Fidelity
**High-fidelity.** 색상, 타이포그래피, 간격, 라운드, 상호작용이 모두 확정값이다. 픽셀 단위로 재현하되, 대상 코드베이스에 디자인 시스템이 이미 있으면 그 토큰으로 매핑한다. 사진은 전부 줄무늬 자리표시자이므로 실제 이미지로 대체한다.

## Interactions & Behavior
- 네비게이션: feed → detail → apply(1→2→3) → done. 뒤로가기는 apply 1단계에서 detail로 복귀
- 피드 필터 칩은 카테고리로 즉시 필터링, 디자이너 목록 칩은 상태로 필터링
- 사진 슬롯 탭 → 파일 선택(`accept="image/*"`) → FileReader로 미리보기 → 다시 탭하면 교체
- 1단계 게이트: 3장 미첨부 시 다음 버튼 비활성
- 완료 화면 진입 시 지원서 상태 초기화
- 전환은 즉시(현재 애니메이션 없음). 필요하면 150–200ms ease-out 페이드/슬라이드 권장
- 반응형: 디자인 기준 폭 402px(iPhone). 모바일 웹 우선, 데스크톱은 중앙 정렬 max-width 480px 권장

## State Management
```
mScreen: 'feed' | 'detail' | 'apply' | 'done'
post: number            // 선택된 모집 id
tab: '전체' | '헤어' | '네일'
step: 1 | 2 | 3
photos: [string|false, string|false, string|false]   // dataURL (실제 구현은 업로드 URL)
cond: { len?, hist?, time? }
dScreen: 'list' | 'detail'; dTab; dApp; accepted: boolean
```

데이터 요구사항(실서비스):
- `posts`: id, category(헤어|네일), title, designer(name, salon, area, instagram, kakaoOpenChat, portfolio[]), reward, duration, dateRange, requirements[]
- `applications`: postId, applicantId, photos{main, current, desired}, conditions{length, history, availability}, note, instagram, kakaoLink, status(신규|검토|보류|수락)
- 이미지 업로드: 3장 필수 검증, EXIF 회전 보정, 리사이즈(장변 1600px), 서명 URL 업로드, 모집 종료 시 비공개 전환
- 오픈채팅 링크는 open.kakao.com 도메인 화이트리스트 검증, 인스타 핸들은 정규식 검증 후 oEmbed/스크린샷 대체
